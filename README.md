# Pandas DataFrame Operations – Week 2 Day 2

## Overview

This project demonstrates advanced Pandas DataFrame operations using Python. It covers merging DataFrames, creating pivot tables, reshaping data, and using method chaining.

## Tasks Completed

### 1. Merge DataFrames

Used `pd.merge()` to combine two DataFrames using different join types:

* Inner Join
* Left Join
* Right Join
* Outer Join

### 2. Pivot Table

Created a pivot table using `pd.pivot_table()` to summarize sales based on:

* Region
* Product
* Sales

### 3. Reshape Data Using `pd.melt()`

Used `pd.melt()` to convert data from **wide format to long format**.

### 4. Method Chaining

Used Pandas method chaining to perform multiple operations together, including:

* Filtering data
* Sorting data
* Selecting columns
* Resetting the index
