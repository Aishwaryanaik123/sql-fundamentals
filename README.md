# Week 12 Day 3 - Security Audit on Data Platform

## Objective
Perform a security audit on a sample data platform to identify account security issues, excessive permissions, sensitive data access risks, and audit logging gaps.

## Tasks Completed
- Reviewed user account status and inactivity.
- Audited privileged role assignments.
- Checked permissions retained by disabled accounts.
- Identified excessive permissions on sensitive datasets.
- Reviewed data access and export logging configuration.
- Documented security findings and recommendations.

## Tools Used
- SQL (PostgreSQL)
- VS Code
- Git and GitHub
- CSV and Markdown

## Deliverables
- SQL security audit checks
- Synthetic audit reference schema
- Audit findings register
- Security audit summary report
- Worklog documentation

## Key Findings
- Disabled account retaining data access
- Inactive account with elevated privileges
- Overly broad access to restricted customer data
- Data-access and export logging gaps
