\# Week 9 Day 2 - MLflow Model Registry



\## Objective

Implement an MLflow Model Registry workflow to manage, version, and track machine learning models.



\## Project Overview

This project demonstrates how to train a machine learning classification model, track experiments using MLflow, and register the trained model in the MLflow Model Registry.



\## Project Structure

\- `scripts/model\_registry.py` - Python script for model training, experiment tracking, and model registration.

\- `docs/model\_registry\_notes.md` - Documentation about MLflow Model Registry.

\- `.gitignore` - Files excluded from Git tracking.



\## Tools and Technologies

Python, MLflow, Scikit-learn, Pandas, Git, and GitHub.



\## Key Activities

1\. Train a machine learning classification model.

2\. Track parameters and evaluation metrics using MLflow.

3\. Register the trained model.

4\. Manage model versions and metadata.

5\. Load the registered model for prediction.



\## Expected Outcome

Understand how MLflow Model Registry helps manage and organize machine learning models throughout their lifecycle.
