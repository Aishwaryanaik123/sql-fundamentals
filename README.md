# KPI Design – Week 3 Day 5

## Overview

This project defines and evaluates key performance indicators (KPIs) for a retail business and presents them through a single-page Power BI dashboard.

## Practical Tasks Completed

- Defined 10 retail business KPIs
- Documented KPI formulas, owners, frequency, and targets
- Classified KPIs as leading or lagging indicators
- Created a single-page KPI dashboard using Power BI
- Created a KPI narrative explaining trends and areas requiring attention

## KPIs Included

1. Revenue Growth
2. Gross Profit Margin
3. Average Order Value
4. Conversion Rate
5. Customer Retention Rate
6. Customer Acquisition Cost
7. Website Traffic Growth
8. Cart Abandonment Rate
9. Customer Satisfaction
10. Inventory Turnover

## Tools Used

Microsoft Excel, Power BI, and Markdown.

## Files

- `kpi_framework.md` – KPI definitions, formulas, owners, frequency, targets, and classifications
- `kpi_data.csv` – KPI dashboard data
- `KPI_Dashboard.pbix` – Power BI dashboard
- `KPI_Dashboard.png` – Dashboard screenshot
- `kpi_narrative.md` – KPI trend and anomaly narrative
