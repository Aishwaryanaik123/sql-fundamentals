# Hypothesis Testing – Week 4 Day 4

## Overview

This project demonstrates hypothesis testing concepts using Python and `scipy.stats` through three business scenarios.

## Practical Tasks

- Formulated null and alternative hypotheses for three business scenarios.
- Performed a one-sample t-test using `scipy.stats`.
- Performed a two-sample t-test to compare two groups.
- Interpreted p-values and confidence intervals.
- Explained Type I and Type II errors with business consequences.

## Tools and Libraries

- Python
- Jupyter Notebook
- NumPy
- Pandas
- SciPy

## Deliverable

- `hypothesis_tests.ipynb`

## Scenarios Covered

### Scenario 1: One-Sample T-Test

Tested whether the average delivery time is significantly different from the target of 5 days.

### Scenario 2: Two-Sample T-Test

Compared the average sales of Region A and Region B to determine whether there is a statistically significant difference.

### Scenario 3: Customer Spending

Tested whether the average customer spending is significantly different from the expected value of ₹1,000.

## Statistical Concepts

- Null Hypothesis (H₀)
- Alternative Hypothesis (H₁)
- Significance Level
- T-statistic
- P-value
- Confidence Interval
- Type I Error
- Type II Error
