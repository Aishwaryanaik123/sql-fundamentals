# NumPy Array Operations - Week 2 Day 5

## Project Overview

This task focuses on practicing NumPy array creation, vectorized operations, indexing, statistical analysis, and performance comparison between NumPy and Python loops.

## Objectives

* Create 1D, 2D, and 3D NumPy arrays.
* Perform vectorized addition and multiplication.
* Calculate aggregate values across different axes.
* Apply Boolean masking and fancy indexing.
* Calculate mean, standard deviation, percentiles, and correlation.
* Compare NumPy performance with Python loops using 1 million rows.

## Tools and Technologies

* Python
* NumPy
* PyCharm
* Git
* GitHub

## File

`numpy_array_operations.py`

## Tasks Performed

The Python program creates 1D, 2D, and 3D arrays and displays their shapes. Vectorized operations are performed for efficient array calculations. Axis-wise sum and mean operations are also demonstrated.

Boolean masking and fancy indexing are used to filter and select specific elements from arrays. Statistical analysis is performed using mean, standard deviation, percentiles, and correlation.

Finally, NumPy vectorized operations are compared with a Python loop using 1 million values to demonstrate the performance advantage of NumPy.

## Result

The NumPy implementation performed significantly faster than the Python loop for processing 1 million values.
