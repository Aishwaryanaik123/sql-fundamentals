# Cynaris Sales Analytics Dashboard - Week 3 Day 4

## Overview
Interactive sales analytics dashboard created using Looker Studio.

## Features
- Total Sales Scorecard
- Sales by Category Bar Chart
- Sales Trend Line Chart
- Sales by Region Pie Chart
- Product Sales, Profit and Quantity Table
- Region Filter
- Custom Dashboard Theme
