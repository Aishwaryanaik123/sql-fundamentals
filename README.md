# W5D5 - AI-Powered EDA on Indian Business Dataset

## Project Overview

This project performs Exploratory Data Analysis (EDA) on an Indian student/business-related dataset using Python and data analysis libraries.

## Dataset

- Rows: 100,000
- Columns: 18
- Dataset: student_performance.csv

## Analysis Performed

- Dataset overview
- Data type analysis
- Missing value analysis
- Duplicate analysis
- Descriptive statistics
- Categorical analysis
- Correlation analysis
- Placement analysis
- Salary package analysis
- Internship vs placement analysis
- Data-driven insights
- Data visualizations

## Key Findings

- Average CGPA: 7.21
- Average salary package: 17.31 LPA
- Placement rate: 68.47%
- Average internships: 1.10
- Average coding skills score: 6.00
- Average DSA score: 5.50
- Average communication skills score: 5.99

## Strong Correlations with Salary

- Internships: 0.43
- DSA Score: 0.40
- CGPA: 0.34
- ML Knowledge: 0.30
- Coding Skills: 0.27
- System Design: 0.21

## Tools Used

Python, Pandas, NumPy, Matplotlib, Seaborn, VS Code, Git, GitHub

The `eda_outputs` folder contains the generated charts and EDA summary.
