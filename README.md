# Data Storytelling Principles — Structure + Narrative (Week 11 Day 1)

## Ready-to-view deliverable
Open `reports/storytelling_presentation.html` in a modern browser. It is an offline presentation with navigation buttons and keyboard arrows. No installation or internet connection is required.

## Project contents
- `data/sales_performance_synthetic.csv` — synthetic sales dataset (2023–2025).
- `reports/storytelling_presentation.html` — seven-part presentation.
- `reports/yearly_sales.svg` — annual trend.
- `reports/monthly_seasonality.svg` — monthly seasonality.
- `reports/region_sales.svg` — regional comparison.
- `reports/product_sales.svg` — product mix comparison.
- `storyboard/storyboard.md` — audience, central message, narrative arc, and call to action.
- `experiment_process.md` — documented analysis and storytelling process.
- `storytelling_checklist.md` — reusable quality checklist.
- `execution_notes.txt` — findings and limitations.
- `src/analyze_story.py` — optional standard-library summary script.
- `PROJECT_INFO.txt` — project metadata.

## Framework
Context → Tension → Insight → Action. Start with the answer, establish the trend, reveal meaningful differences, explain why they matter, and end with a specific decision.

## Note
All records are synthetic and illustrative, not actual company performance.
