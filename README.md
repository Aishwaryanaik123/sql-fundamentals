# Week 1 Day 5 — Pandas Practice

## Overview

This project focuses on practicing **Pandas** for data analysis and data cleaning using Python.

The objective is to learn how to load, explore, clean, modify, and export data using Pandas.

## Tools & Technologies

* Python
* Pandas
* CSV
* PyCharm
* Git
* GitHub

## Project Files

* `pandas_practice.py` — Python program containing Pandas practice and data-cleaning operations.
* `employees_dataset.csv` — Original employee dataset.
* `cleaned_employees.csv` — Cleaned employee dataset generated using Pandas.
* `cleaned_employees_dataset.csv` — Cleaned employee dataset generated during practice.
* `README.md` — Project documentation.

## Tasks Performed

* Loaded CSV data using Pandas.
* Displayed and explored the dataset.
* Checked rows and columns.
* Identified missing values.
* Cleaned the dataset.
* Performed data manipulation using Pandas.
* Created calculated columns.
* Exported the cleaned data to CSV files.

## Learning Outcomes

Through this practice, I learned how to:

* Work with Pandas DataFrames.
* Read and write CSV files.
* Inspect datasets.
* Handle missing and inconsistent data.
* Perform basic data cleaning.
* Create new columns.
* Export processed data.

## How to Run

1. Install Python.
2. Install Pandas:

```bash
pip install pandas
```

3. Open the project in PyCharm.
4. Run the Python file:

```bash
python pandas_practice.py
```

5. The cleaned dataset will be generated as CSV files.
