This repository contains my SQL practice work for **Week 1 – Day 3**, focused on **SQL Aggregations** using MySQL and MySQL Workbench.

## Topics Covered

* Aggregate Functions
* `COUNT()`
* `SUM()`
* `AVG()`
* `MIN()`
* `MAX()`
* `GROUP BY`
* `HAVING`
* Combining aggregate functions with filtering and grouping

## Tools & Technologies

* MySQL

To understand how aggregate functions are used to summarize data and how `GROUP BY` and `HAVING` can be used to analyze grouped data.
