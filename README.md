# Power BI Fundamentals – Week 3 Day 1

## Project Overview

This project focuses on building an interactive Sales Analytics Dashboard using Microsoft Power BI. The report provides sales, profit, order, and quantity insights through interactive visualizations and slicers.

## Dataset

**File:** `sales_data.csv`

The dataset contains sales-related information including:

* OrderID
* Order Date
* Category
* Product
* Region
* Sales
* Profit
* Quantity
* Total Sales
* Total Profit
* Total Orders
* Total Quantity

## Power BI Report Pages

### 1. Overview

The Overview page contains the main Sales Analytics Dashboard with:

* Total Sales
* Total Profit
* Total Orders
* Sales by Category
* Sales by Region
* Monthly Sales Trend
* Sales by Product
* Profit by Region

Interactive slicers:

* Order Date
* Region
* Category
* Product

### 2. Drill-Down

The Drill-Down page provides more detailed analysis through:

* Sales by Product
* Profit by Region
* Sales by Category

### 3. KPI Summary

The KPI Summary page displays key performance indicators:

* Total Sales
* Total Profit
* Total Orders
* Total Quantity
