\# Probability Distributions – Week 4 Day 2



\## Overview



This project covers basic probability concepts and probability distributions using Python. The practical tasks demonstrate conditional probability, the normal distribution, binomial distribution, and the Central Limit Theorem through calculations, plots, and simulations.



\## Practical Tasks



\### 1. Basic Probability



Calculated:



\* P(A)

\* P(A ∩ B)

\* P(A|B)



using a contingency table.



\### 2. Normal Distribution



Plotted a normal distribution and identified the 68-95-99.7 rule.



\### 3. Binomial Distribution



Simulated a binomial distribution using NumPy.



\### 4. Central Limit Theorem



Demonstrated the Central Limit Theorem using a sampling simulation.



\## Tools and Libraries



Python, Jupyter Notebook, NumPy, Pandas, and Matplotlib.



\## Deliverable



`probability\_notebook.ipynb`



The notebook contains the calculations, distribution plots, and simulations for all practical tasks.
