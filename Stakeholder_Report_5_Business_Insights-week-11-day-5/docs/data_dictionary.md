# Data Dictionary

| Field | Type | Description |
|---|---|---|
| month | YYYY-MM | Calendar month |
| year | Integer | Calendar year |
| region | Text | North, South, East, or West |
| product_category | Text | Product category |
| sales | Decimal | Synthetic sales revenue |
| profit | Decimal | Synthetic profit |
| orders | Integer | Synthetic order count |
| average_order_value | Decimal | Sales divided by orders |
| profit_margin_pct | Decimal | Profit divided by sales × 100 |
