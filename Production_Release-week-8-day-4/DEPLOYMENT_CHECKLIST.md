# Deployment and QA checklist

## Before deployment
- [ ] Confirm `index.html`, `style.css`, and `script.js` are at the repository root.
- [ ] Confirm the correct repository and branch are selected.
- [ ] Confirm static hosting settings: no build command; root/output directory `.`.

## After deployment
- [ ] Open the actual deployment URL in a private/incognito window.
- [ ] Confirm the homepage loads without a hosting 404.
- [ ] Test on desktop and a narrow/mobile viewport.
- [ ] Click **Refresh status** and confirm the status message updates.
- [ ] Add an issue item; confirm it appears.
- [ ] Mark an item complete; confirm strike-through and open count update.
- [ ] Test All / Open / Completed filters.
- [ ] Remove an item and confirm it disappears.
- [ ] Submit an empty form and confirm browser validation appears.
- [ ] Check browser developer console for JavaScript errors.
- [ ] Check hosting/deployment logs for platform errors.
- [ ] Confirm there are no failed requests or HTTP 500 responses. This static app has no API requests; do not claim this check passed until you have tested the live URL.
- [ ] Record the live URL and date/time of verification.
