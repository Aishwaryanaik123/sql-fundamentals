\# Vanna SQL Analyst - Week 6 Day 1



\## Overview



This project implements a natural-language SQL analyst using Vanna concepts with a local Ollama LLM and DuckDB.



\## Features



\- Connected DuckDB database

\- 5 question-to-SQL training examples

\- 10 natural-language SQL tests

\- Manual SQL validation

\- SQL execution using DuckDB

\- SQL safety validation

\- Flask API endpoint

\- End-to-end CIA SQL Analyst API



\## Technologies



Python, Vanna 2.0.2, Ollama, Llama 3.2:3b, DuckDB, Flask, Waitress, Requests, Pandas
