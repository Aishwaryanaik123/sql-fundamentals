# Demo Readiness Checklist

## Before the demo
- [ ] Replace all `[ADD ...]` placeholders.
- [ ] Select two or three completed projects to demonstrate.
- [ ] Verify every metric against the final notebook, query output, or dashboard.
- [ ] Open the required files and confirm they work.
- [ ] Keep datasets and screenshots in clearly named folders.
- [ ] Prepare a short explanation of the objective, process, and findings for each project.
- [ ] Test dashboard filters, slicers, and visuals.
- [ ] Check that no passwords, API keys, or private information are visible.
- [ ] Keep a backup copy of the presentation files.

## During the demo
- [ ] Introduce the project objective.
- [ ] Explain the dataset briefly.
- [ ] Show the main analysis or dashboard.
- [ ] Explain verified findings in simple language.
- [ ] Answer questions clearly and honestly.

## After the demo
- [ ] Note reviewer feedback.
- [ ] Make any requested corrections.
- [ ] Confirm the GitHub branch contains the final files.
