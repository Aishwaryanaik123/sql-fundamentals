# Data Dictionary
| Column | Type | Description |
|---|---|---|
| order_date | Date | First day of reporting month |
| year | Integer | Calendar year |
| month | Integer | Calendar month number |
| region | Text | North, South, East, or West |
| product_category | Text | Electronics, Furniture, or Office Supplies |
| orders | Integer | Synthetic order count |
| sales | Decimal | Synthetic sales revenue (USD) |
| profit | Decimal | Synthetic profit (USD) |

All records are synthetic and created for training.
