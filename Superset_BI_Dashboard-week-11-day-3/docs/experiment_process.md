# Experiment Process – Week 11 Day 3

1. Generated a synthetic monthly sales dataset for four regions and three product categories across 2024–2025.
2. Prepared aggregation queries for KPIs, regional sales, monthly trend, product mix, and regional detail.
3. Designed a stakeholder dashboard with KPI cards and the five requested visualization types.
4. Exported a static PNG preview and individual chart preview images.
5. Added Docker Compose and Superset configuration references for local setup.
6. Documented database registration, chart creation, dashboard assembly, PNG export, and stakeholder sharing.

## Limitations
- Dataset is synthetic and not company/customer data.
- Superset was not started in this build environment.
- The PNG is a locally generated dashboard preview, not a native Superset screenshot/export.
- A live Superset export requires Docker Desktop, a running Superset instance, a connected database, and chart recreation using the guide and SQL.
