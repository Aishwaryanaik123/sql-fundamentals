# Data Storytelling Quality Checklist

## Audience and purpose
- [ ] Identify the audience and the decision they need to make.
- [ ] Write the central message in one sentence.
- [ ] Select only evidence that supports or challenges that message.

## Narrative
- [ ] Open with the key takeaway.
- [ ] Give enough context to understand the problem.
- [ ] Reveal a tension, contrast, or meaningful pattern.
- [ ] Explain why the insight matters.
- [ ] Recommend a specific action.
- [ ] Close with a decision and follow-up measure.

## Visual design
- [ ] One main idea per slide.
- [ ] Choose charts that answer the question.
- [ ] Use takeaway-led chart titles.
- [ ] Label units, periods, and comparisons.
- [ ] Avoid clutter and misleading scales.
- [ ] Use consistent formatting.

## Credibility
- [ ] State data source and time period.
- [ ] Distinguish facts, interpretations, and recommendations.
- [ ] Include limitations.
- [ ] Avoid implying causation from simple comparisons.
- [ ] Validate calculations.
