# Example insights from the demo dataset

These observations are calculated from the included **sample/demo dataset only** and should not be presented as real-world findings.

1. Average salary varies across branches; the bar chart makes the branch-level comparison easy to scan.
2. The CGPA-versus-salary scatter plot allows users to inspect whether higher CGPA is associated with higher salary in this small sample, while distinguishing placed and not-placed records.
3. The placement distribution chart summarizes the proportion of placed and not-placed sample records.
4. The Graph Objects chart compares average technical and communication scores by branch.
5. The Dash app's dropdown filters both charts to a selected branch.

For a real assignment, rerun the scripts using the official dataset and update this file with verified, data-driven findings.
