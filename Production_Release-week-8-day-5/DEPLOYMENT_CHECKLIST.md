# Deployment verification checklist

This checklist is intentionally unchecked until the actions have actually been performed.

- [ ] Deploy the folder to Vercel or Render.
- [ ] Add the production URL to README and PR description.
- [ ] Open the URL in a private/incognito browser window.
- [ ] Verify all visible interactions and responsive layouts.
- [ ] Inspect browser console and network requests.
- [ ] Review hosting logs for 500 errors.
- [ ] Test any required backend/API routes (not included in this static demo).
- [ ] Record a 3-minute walkthrough of the deployed URL.
- [ ] Upload the recording and add a share link.
- [ ] Open the final PR on the intended feature branch.
- [ ] Confirm the PR does not include unrelated folders or merge into master.
