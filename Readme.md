# Excel Pivot and Power Query Sales Analysis

This project is an Excel-based sales analysis using PivotTables, PivotCharts, Power Query, slicers, and KPI calculations.

## Practical Tasks

- Created a PivotTable summarising revenue by region, product, and quarter
- Created Margin and Margin % calculations
- Created Growth % analysis
- Used Power Query to combine multiple CSV files
- Created a PivotChart
- Added dynamic slicers for region, product, and quarter
- Created a KPI Summary worksheet
- Applied conditional formatting to KPI thresholds

## Power Query

Four CSV files were imported and combined using Power Query:

- sales_q1.csv
- sales_q2.csv
- sales_q3.csv
- sales_q4.csv

The combined data was transformed and loaded into Excel.

## PivotTable

The PivotTable analyses:

- Revenue by Region
- Revenue by Product
- Revenue by Quarter
- Margin
- Growth %

## KPI Summary

The KPI Summary contains:

- Total Revenue
- Total Cost
- Total Margin
- Margin %
- Total Quantity
- Total Orders

## PivotChart and Slicers

A PivotChart was created to visualise quarterly revenue by region.

Dynamic slicers were added for:

- Region
- Product
- Quarter

## Conditional Formatting

Conditional formatting was applied to Margin % to highlight different KPI threshold levels.
