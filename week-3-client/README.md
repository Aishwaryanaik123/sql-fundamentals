# Week 3 – Data Pipeline + Baseline Metrics

## Project objective
Build a repeatable data pipeline for the three Week 1 source files, run basic validation, load the processed tables into SQLite, and calculate baseline metrics using SQL.

## Dataset inventory
| Source | Rows | Columns | Grain |
|---|---:|---:|---|
| Real estate listings | 600 | 15 | One row per listing |
| Customer profiles | 200 | 10 | One row per customer |
| Product catalogue | 50 | 7 | One row per product |

The datasets represent different business domains. They are processed and analyzed independently; no unsupported cross-domain join is performed.

## Pipeline flow
1. Read CSV files from `data/raw/`.
2. Normalize column names and trim whitespace in text fields.
3. Parse available date fields.
4. Validate candidate key uniqueness and non-nullness.
5. Write processed CSV files to `data/processed/`.
6. Load tables into `data/processed/analytics.db` (SQLite).
7. Execute SQL baseline queries and segment-level queries.
8. Export baseline metrics and quality checks to `reports/`.
9. Record pipeline execution in `logs/pipeline.log`.

## Baseline metrics included
- Real estate: total listings, sold listings, sold rate, median listing price, average days on market, and city-level breakdown.
- Customers: customer count, churned customers, churn rate, total revenue, average revenue/customer, average orders/customer, and acquisition-channel breakdown.
- Products: product count, total stock, products with stock below average monthly sales, average gross margin percentage, and category breakdown.

**Metric caveats:** The `sold` and `Churned` fields are interpreted as binary indicators (1 = yes). Revenue and product price units/currency, date coverage, and business definitions should be confirmed with the stakeholder. The product gross margin percentage is calculated as `(MRP - COGS) / MRP × 100`; it is a catalogue-based margin proxy, not realized sales margin.

## Run locally
Requires Python 3.9+.

```bash
python -m venv .venv
# Windows PowerShell:
.venv\Scripts\Activate.ps1
# macOS/Linux:
source .venv/bin/activate

python -m pip install -r requirements.txt
python src/run_pipeline.py
```

Run the pipeline again after replacing a raw CSV to refresh processed data and reports.
