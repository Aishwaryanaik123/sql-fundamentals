# Experiment Process – Week 11 Day 4

1. Generated a synthetic monthly sales dataset for four regions and three product categories across 2024–2025.
2. Created CSV and SQLite versions of the dataset for self-serve BI practice.
3. Prepared SQL examples for KPI cards, regional sales, monthly trend, product mix, and regional detail.
4. Designed a dashboard layout containing bar, line, pie, table, and metric visualizations.
5. Generated a static dashboard preview and individual chart previews.
6. Added Docker Compose reference configuration and documentation for Metabase setup, data connection, dashboard creation, export, and stakeholder sharing.

## Limitations
- The dataset is synthetic and does not represent real company or customer information.
- Metabase was not launched in this build environment.
- The PNG is a locally generated preview, not a native Metabase dashboard export.
- A live export requires Docker Desktop, a running Metabase instance, a connected sales database, and recreating the visualizations using the guide.
